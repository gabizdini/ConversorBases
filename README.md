# Conversor de Bases Numéricas

Sistema Web desenvolvido em Python utilizando Flask para conversão entre diferentes bases numéricas.

## Funcionalidades

- Conversão Decimal → Binário, Hexadecimal e Octal
- Conversão Binário → Decimal, Hexadecimal e Octal
- Conversão Hexadecimal → Decimal, Binário e Octal
- Conversão Octal → Decimal, Binário e Hexadecimal

## Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS
- JavaScript
